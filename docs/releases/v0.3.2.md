# O-QT MCP v0.3.2 maintenance candidate

This patch candidate enforces configured JWT algorithms and requires issuer,
audience, subject, and expiration claims. JWKS outage fallback is bounded to one
extra cache TTL. Existing production tokens must include `exp` and `sub`.

Patched AnyIO, cryptography, Click, and urllib3 are required by the project;
the Poetry lock is refreshed. Runtime version fallbacks and report provenance
now agree with the 0.3.2 package metadata. Local development binds to loopback.
Reports retain their legacy MD5 field and add a SHA-256 digest.

Offline validation: 104 tests pass, including genuine signed-token negative
cases, while 19 configured live/slow Toolbox tests remain skipped. The final
dependency scan has no known advisories. The new recurring Python security
check gates medium/high findings. The dependency audit schedule is refreshed.

Before release, merge only after hosted CI passes, verify the scheduled audit
is active, and perform a controlled authenticated Toolbox smoke. Live Toolbox
