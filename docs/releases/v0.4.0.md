# v0.4.0 — Unreleased SDK2 migration candidate

Stable MCP Python SDK 2.2.0 adds protocol 2026-07-28 HTTP and authenticated dual-generation stdio. The released HTTP handlers remain available, and Python 3.10 plus the source/container distribution are retained.

OIDC/RBAC, privacy audit, scientific schemas/provenance, applicability-domain warnings and human review checkpoints stay in the existing handlers. Hosting must configure the modern Host/Origin allowlists and review the configurable body bound before rollout. See [the migration guide](../mcp_sdk2.md).

Local and hosted checks must pass before a separately approved deployment/release. Offline compatibility fixtures do not claim live OECD QSAR Toolbox qualification.
